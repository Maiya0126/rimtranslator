【一句话简介】
RimWorld 离线翻译提取工具——不进游戏，图形界面选 Mod，
一键提取 → 术语回填 → AI 翻译 → 人工审阅 → 写入。
完全免费 · 开源 · 本地运行。

────────────────────────────────────────
一、下载哪个版本？
────────────────────────────────────────

  ▸ RimTranslator-v1.2.7-win-x64-full.zip（约 55 MB）
    完整版：单个 exe 自带 .NET 运行时，解压双击即用，
    无需安装任何环境。
    —— 拿不准就下这个，100% 能跑。

  ▸ RimTranslator-v1.2.7-win-x64-lite.zip（约 0.8 MB）
    精简版：单个 exe，需要电脑已安装 .NET 8 桌面运行时。
    已装过运行时或想省流量的选这个。
    （运行时官方下载：
     https://dotnet.microsoft.com/download/dotnet/8.0
     选 ".NET Desktop Runtime 8.x x64"）

  两个版本功能完全一致，只是体积不同。

────────────────────────────────────────
二、快速上手（5 步）
────────────────────────────────────────

  1. 解压 zip，双击 RimTranslator.exe 启动

  2. 顶部选来源（创意工坊 / 本地 Mod / 自定义目录），
     点「刷新列表」扫描

  3. 设置游戏版本（如 1.6）和目标语言（如 简体中文）
     —— 目标语言是你要翻译成什么语言；
        提取以 Mod 自带的 English 为源

  4. 搜索框过滤 → 单击选中 Mod（Ctrl/Shift 可多选）
     → ③ 区三个按钮选操作（也可右键列表）：
       · 提取：只生成待翻译模板，写入 Mod 自己的 Languages
       · 提取并AI翻译：提取 → 术语回填 → AI 翻译
         → 审阅 → 写入该 Mod 的 Languages
       · 生成独立汉化Mod：同上，但输出为全新汉化 Mod
         文件夹（自动生成 About.xml，可直接上传工坊）。
         需先填「译者名」（作为新 Mod 的作者署名，
         填一次会记住）；
         描述会保留原 Mod 的描述并注明原作者；
         保存位置在该按钮右侧选择

  5. 审阅窗口逐条检查（双击译文可修改）
     → 「确认写入」→ 完成（写盘前自动备份 .bak）

────────────────────────────────────────
四、常见问题
────────────────────────────────────────

  Q：双击打不开 / 闪退？
  A：精简版请先确认已装 .NET 8 桌面运行时（见上文链接）；
     或直接换完整版。

  Q：提示 405 / 端点错误？
  A：端点只填域名即可（工具自动补全路径）；
     仍报错请检查密钥是否有效、账户是否有额度。

  Q：扫描不到创意工坊 Mod？
  A：确认 Steam 路径正确（默认自动识别）；
     也可用「自定义目录」手动指向 workshop/content/294100。

  Q：翻译结果里专有名词不对？
  A：在「自定义词库」里添加同名英文词条、填入你的译法，
     下次翻译即优先采用你的版本。

  Q：覆盖原文件安全吗？
  A：任何写入前自动生成 .bak 备份；
     写创意工坊目录前会弹覆盖警告。
